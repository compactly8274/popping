## Deviations from the spec

- **Two extra harness flows.** The spec names four (taps, touchDrag,
  setHidden, keepalive). `flow-h1-desktop` proves the new 1280 context
  really is a desktop and that the `window.open` and clipboard stubs catch
  a real app call (a card's context menu); `flow-h1-pref-store` proves the
  new preference store, including a reload. Without them those two pieces
  would ship untested until PR3a and PR2b.
- **`installClock(page)`.** The spec has `touchDrag` sleep in Node "when the
  clock is installed". A flow can't ask Playwright whether it is, so
  `installClock` sets `page._clockInstalled` and `touchDrag` skips the rAF
  wait then. `flow-fn-quiet-poll` uses it.
- **`touchDrag` `steps` default.** Unspecified in the spec; 10 (a 400px drag
  is 40px per move, above Chromium's ~40px floor for page touch moves).
- **The keepalive flow drives real app code.** It keeps the view events
  queued (a `requestIdleCallback` that never fires) and refuses the beacon
  (`sendBeacon` returns false), so hiding the page takes
  `interactions.ts`'s keepalive `fetch` fallback. `sendBeacon` is not
  stubbed in other flows.
- **Where the local loop lives.** The plan names no file;
  `frontend/scripts/iphone-audit/README.md` already had the local smoke run
  and is the file the Rules say to update, so the full recipe (backend
  and frontend) is its new "Local loop" section.
- **Mutation restores.** The unit was not committed while the checks ran, so
  `git checkout -- <file>` would have dropped the H1 edits. Each scratch
  edit was made on a pristine copy and restored from it, with a byte-for-byte
  compare in place of `git diff --exit-code`.
- **`ARCHITECTURE.md` unchanged:** H1 adds no process-local state.
- `/code-review high` was not run inside this session; it is the unit's
  review step before merge.
